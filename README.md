# Ranjith Ramachandran – Developer Portfolio

Pure HTML + CSS (no frameworks, no npm libraries needed). Responsive for mobile, tablet, laptop and desktop.

## Run in VS Code
1. Extract the zip and open the `ranjith-portfolio` folder in VS Code (File > Open Folder).
2. Install the recommended extension **Live Server** (VS Code will suggest it).
3. Right-click `index.html` > **Open with Live Server**.

Or with Node.js: `npm start`

## Structure
- `index.html` – page content
- `css/style.css` – all styles and hover animations
- `assets/photo.webp` – profile photo (transparent background)
- `assets/Ranjith_Ramachandran_CV.pdf` – file downloaded by the Download CV button

## Customise
- Change text in `index.html`.
- Change colours in `css/style.css` (`:root` variables, `--o` is the orange).
- Replace the CV by overwriting the PDF in `assets/` (keep the same name).
